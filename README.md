# Прогнозирование поведения абитуриентов во время приемной кампании

## Описание проекта

Данный проект посвящён разработке математических и программных инструментов для повышения эффективности управления приёмной кампанией университета (на примере СПбГЭУ) с помощью современных методов анализа данных, прогнозирования и оптимизации

## Выполненные задачи
- Прогнозирование суточной динамики подачи заявлений на зачисление в вуз (1 этап приёмной кампании) с помощью статистических моделей (SARIMA), ML моделей (Random Forest, SVR, XGBoost) и DL моделей (MLP, RNN, LSTM).
- Оптимизация численности персонала приёмной комиссии: разработан симуляционно-итеративный алгоритм планирования распределения персонала с учётом вероятностного характера нагрузки, индивидуальных скоростей обработки заявок сотрудниками и требуемого уровня обслуживания заявок.
- Прогнозирование подачи оригиналов документов (2 этап приёмной кампании): построена классификационная модель (CatBoost), позволяющая оценивать вероятность подачи/отзыва оригиналов каждым абитуриентом для приоритизации коммуникаций со стороны сотрудников приёмной комиссии.
- Интерактивный дашборд на Python (Dash), интегрирующий все разработанные модели и инструменты анализа.

## Краткие итоги
- Благодаря разработанному алгоритму оптимизации персонала достигнуто снижение трудозатрат приёмной комиссии без ухудшения качества обслуживания.
- Разработан инструмент поддержки управленческих решений, объединяющий все разработанные инструменты и дающий сотрудникам приёмной комиссии наглядную информацию для планирования приёмной кампании и коммуникаций с абитуриентами.
